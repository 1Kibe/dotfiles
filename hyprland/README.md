# hyprland

Espaço reservado para a configuração do **Hyprland** e de um **Quickshell** personalizado. Ainda não há configs aqui.

| Pasta no repo | Vira, depois do `stow` |
|---|---|
| `hyprland/.config/hypr/` | `~/.config/hypr/` |
| `hyprland/.config/quickshell/` | `~/.config/quickshell/` |

- Enquanto as pastas só tiverem `.gitkeep`, o `install.sh` pula este ambiente mesmo que ele seja escolhido.
- Os pacotes entram na seção `[hyprland]` de `packages/arch.txt` (e das outras distros).
- Este README fica fora dos links: o GNU Stow ignora `README.*` na raiz de cada pacote.
